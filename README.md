## Ajouter un projet
Dans `index.html`, duplique la carte `<article class="project-card">`, puis modifie son image (`--project-image`), son titre, sa description et le lien `Consulter`.

Crée le dossier correspondant dans `projets/` avec un `index.html` copié depuis `projets/laboratoire-reseau/index.html`. Modifie le titre et le chemin affiché en haut de la page, puis dépose les fichiers du projet dans ce même dossier. Sur GitHub Pages, la liste est générée automatiquement à la publication.
